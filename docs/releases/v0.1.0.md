# git-hint v0.1.0

First release of the HINT client.

## Platforms

| Platform | Status | Tested on |
|---|---|---|
| macOS arm64, amd64 | supported | macOS 15.7 (GitHub runners `macos-15` arm64 and `macos-15-intel` amd64) |
| Linux amd64, arm64 | supported | Ubuntu 24.04.5 (GitHub runners `ubuntu-24.04` amd64 and `ubuntu-24.04-arm` arm64) |
| Windows | deferred | not built, not supported, not tested |

Older systems are not tested. Linux programs are statically linked (no C library dependency). The archives are reproducible: the same commit and Go version give byte-identical files. Verify each archive with `SHA256SUMS` and, optionally, `gh attestation verify` ([install](https://github.com/neprel/git-hint/blob/main/docs/client/install.md)).

## Versions

- HINT data standard: writes 0.1.0, reads 0.1.
- MCP: stdio; protocol versions as listed by `git hint version --capabilities` (checked with OpenCode at 2025-11-25).
- Agents: OpenCode adapter, checked with OpenCode 2.0.26. Claude Code and Codex are not supported in this version.

## Contents

- Local collection of repository structure (Go declarations and imports with the Go standard library parser; other languages at file level) and OpenCode agent activity, without content or names.
- Export packages in file mode and API mode, with a privacy report; no default server; nothing is sent without `git hint recommend` or the local MCP upload rule.
- Recommendation validation and local Markdown plans.
- `git hint mcp`: MCP server with 12 tools, including read-only navigation of the local index.
- `git hint version --capabilities`: build, languages, MCP, adapters and optional tools.

## Known limits

- No embedded tree-sitter grammars; languages other than Go are covered at file level.
- External indexers (`scip-*`, `sem`) are detected but not used.
- `git hint --help` opens Git's manual page lookup; use `git hint help`.
